Guarda contexto persistente Malahor para poder continuar despues sin perder estado.

Foco opcional del usuario: $ARGUMENTS

Instrucciones:

1. Resume la sesion actual en formato compacto: objetivo, requisitos, decisiones, completado, activo, bloqueos, archivos relevantes, validaciones y proximo paso exacto.
2. Guarda el resumen con Mnemo `mem_session_summary` usando el proyecto canonico.
3. Si hay una decision tecnica estable, bug o patron reusable, guarda tambien una observacion `mem_save` con tipo adecuado.
4. Si el cambio afecta PM/manual/documentacion persistente y Obsidian esta habilitado para el proyecto, actualiza solo la nota especifica necesaria.
5. Responde con el id o confirmacion de memoria y un resumen de 5 bullets maximo.

No llenes la ventana con detalles historicos; guarda el detalle en memoria y muestra solo la confirmacion.
