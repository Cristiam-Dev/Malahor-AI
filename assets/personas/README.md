# Personas Malahor

Personas markdown opcionales para ajustar tono, prioridades y estilo de trabajo del agente sin fijar perfiles rigidos.

## Regla

Malahor no depende de perfiles fijos. El orquestador debe inferir contexto dinamicamente y usar estas personas solo como guias configurables.

## Archivos

- `neutral.md`: persona base recomendada.
- `custom-template.md`: plantilla para crear una persona propia.

## Uso Esperado

1. Empezar con `neutral.md`.
2. Copiar `custom-template.md` fuera del repo si se necesita una persona especifica.
3. Mantener instrucciones breves, verificables y no contradictorias.
4. No incluir secretos ni datos sensibles.
