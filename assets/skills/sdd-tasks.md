# sdd-tasks

Dividir el diseno en tareas ejecutables y verificables.

## Pasos

1. Crear tareas pequenas.
2. Ordenarlas por dependencia.
3. Asociar cada tarea a una validacion.
4. Separar implementacion, calidad y verificacion.

## Salida

- Lista de tareas.
- Validacion por tarea.
- Proxima fase: `sdd-apply`.
