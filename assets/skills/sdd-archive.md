# sdd-archive

Cerrar el flujo SDD y guardar conocimiento relevante.

## Pasos

1. Resumir decision, implementacion y validacion.
2. Guardar en Mnemo decisiones, bugs, patrones o aprendizajes.
3. Indicar estado final y siguientes pasos.
4. No crear archivos de cierre dentro del repo objetivo salvo pedido explicito.

## Salida

- Resumen final.
- Memorias guardadas.
- Estado de commit sugerido si aplica.
