# sdd-init

Iniciar un cambio SDD y decidir si el flujo completo aplica.

## Usar Cuando

- El cambio sea no trivial.
- El usuario pida una feature, refactor, integracion o migracion.
- Exista riesgo de romper comportamiento existente.

## Pasos

1. Identificar objetivo del usuario.
2. Definir alcance inicial.
3. Detectar restricciones conocidas.
4. Confirmar si requiere SDD completo o flujo liviano.

## Salida

- Objetivo.
- Alcance.
- Riesgos iniciales.
- Proxima fase: `sdd-explore`.
