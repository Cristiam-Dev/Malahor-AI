# git-status-review

Revisar el estado del repositorio antes de proponer commits o continuar trabajo.

## Pasos

1. Revisar archivos modificados, agregados y eliminados.
2. Separar cambios relacionados del bloque actual y cambios ajenos.
3. Revisar diff de los archivos relevantes.
4. Revisar ultimos commits para mantener estilo.
5. Informar si hay riesgo de mezclar cambios no relacionados.

## Salida

- Estado del worktree.
- Archivos del bloque actual.
- Cambios posiblemente ajenos.
- Riesgos antes de commit.
- Siguiente accion recomendada.
