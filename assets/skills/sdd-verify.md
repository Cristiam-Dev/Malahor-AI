# sdd-verify

Verificar la implementacion contra la especificacion.

## Pasos

1. Comparar cambios contra criterios de aceptacion.
2. Confirmar que no se amplio alcance.
3. Revisar riesgos residuales.
4. Preparar resumen para el usuario.

## Salida

- Criterios cumplidos.
- Criterios no cumplidos.
- Riesgos residuales.
- Proxima fase: `sdd-archive` si todo esta aceptable.
