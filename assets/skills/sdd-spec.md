# sdd-spec

Convertir la propuesta aceptada en especificacion verificable.

## Pasos

1. Definir comportamiento esperado.
2. Definir casos de aceptacion.
3. Definir casos fuera de alcance.
4. Definir criterios de error y regresion.

## Salida

- Especificacion funcional.
- Criterios de aceptacion.
- No objetivos.
- Proxima fase: `sdd-design`.
