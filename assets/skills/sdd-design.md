# sdd-design

Disenar la implementacion antes de dividir tareas.

## Pasos

1. Mapear componentes afectados.
2. Definir cambios de datos, interfaces o contratos.
3. Identificar dependencias y orden de implementacion.
4. Confirmar que no se crean archivos de Malahor dentro del repo objetivo.

## Salida

- Diseno tecnico.
- Archivos previstos.
- Impacto esperado.
- Proxima fase: `sdd-tasks`.
