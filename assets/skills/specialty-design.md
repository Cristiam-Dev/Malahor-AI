# specialty-design

Guia de especialidad para trabajo de diseno: UI/UX, branding, sitios web y material visual. Cubre la parte de diseno antes de la implementacion.

## Usar Cuando

- La tarea pide diseno de interfaz, experiencia de usuario, branding o sitio web.
- Se definen paletas, tipografia, jerarquia visual o sistema de diseno.
- Se evaluan o mejoran flujos de usuario, navegacion o conversion.
- Se crean piezas visuales: banners, posters, mockups o presentaciones.

## Preguntas Guia

1. Quien es el usuario, que necesita lograr y que emocion debe sentir?
2. Cual es el mensaje o accion principal por pantalla o pieza?
3. Que jerarquia visual guia el ojo: tamano, peso, color, espacio?
4. Que patrones conoce el usuario y que espera encontrar donde?
5. Como se ve en movil y en escritorio, y como se comporta el contenido?
6. Que pasa en estados vacios, errores y primeras visitas?

## Puntos de Revision

- Jerarquia: una accion o mensaje principal claro por vista.
- Tipografia: maximo dos familias, escala consistente, legibilidad primero.
- Color: paleta limitada y accesible; contraste WCAG AA como minimo.
- Espaciado: ritmo consistente; mas espacio alrededor de lo importante.
- Consistencia: componentes, estados y vocabulario coherentes en todo el flujo.
- Accesibilidad: texto alternativo, foco, contraste y no depender solo del color.

## Anti-Patrones

- Llenar la vista de elementos que compiten por atencion.
- Elegir colores o tipografias sin relacion con la marca ni el uso.
- Disenar primero desktop y adaptar movil como idea tardia.
- Depender de iconos o color sin etiquetas ni alternativas.
- Copiar estilos de moda sin razon funcional ni de marca.
- Olvidar estados: vacio, carga, error, exito y primera visita.

## Salida

- Propuesta de jerarquia, paleta, tipografia y espaciado.
- Flujo o pantallas clave con su mensaje principal.
- Notas de accesibilidad y responsive.
- Decisiones de marca o sistema de diseno para guardar en Mnemo.

## Integracion Con SDD

- Usar antes de `sdd-design` cuando el cambio sea de experiencia o visual.
- Para piezas unicas (banner, poster) aplicar directo sin flujo SDD.
- Guardar decisiones de identidad o sistema de diseno en Mnemo.
