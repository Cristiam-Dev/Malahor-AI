# sdd-propose

Proponer alternativas antes de fijar especificacion.

## Pasos

1. Plantear solucion minima viable.
2. Incluir alternativas solo si hay tradeoffs reales.
3. Explicar riesgos y validacion necesaria.
4. Pedir confirmacion si el alcance cambia.

## Salida

- Propuesta recomendada.
- Alternativas descartadas, si aplican.
- Riesgos.
- Proxima fase: `sdd-spec`.
