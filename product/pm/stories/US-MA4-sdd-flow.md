# US-MA4 - Ejecutar flujo SDD para cambios no triviales

## Historia

Como desarrollador, quiero que Malahor active un flujo SDD para cambios no triviales para que las implementaciones tengan especificacion, diseno, tareas, calidad y verificacion.

## Criterios de aceptacion

- El orquestador identifica cambios no triviales.
- El flujo SDD incluye init, explore, propose, spec, design, tasks, apply, quality, verify y archive.
- La fase `sdd-quality` corre antes de `sdd-verify`.
- Si calidad falla, el flujo vuelve a aplicacion antes de cerrar.
- El resultado se archiva en Mnemo.
