# US-MA3 - Generar grafo de codigo fuera del repositorio

## Historia

Como desarrollador, quiero que Malahor genere el mapa estructural del codigo fuera del repo para que el agente pueda orientarse sin crear archivos en mi proyecto.

## Criterios de aceptacion

- Malahor verifica si `graphifyy` esta instalado.
- Si no esta instalado, el instalador propone instalarlo con pip.
- Los grafos se crean en `~/.malahor/graphs/$PROJECT/`.
- El comando de generacion usa `GRAPHIFY_OUT`.
- Ningun archivo de Graphify queda dentro del repo objetivo.
